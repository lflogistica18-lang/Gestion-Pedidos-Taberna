# Merge: Personal + logo (2026-11-27)

Se puede hacer desde el celu (navegador o app de GitHub). Hacer el Merge **no publica nada**: la app del local
no cambia hasta que yo la publique (a las 16 h).

1. Abrí https://github.com/lflogistica18-lang/Gestion-Pedidos-Taberna/compare/master...personal-y-logo
2. Botón verde **Create pull request** → otra vez **Create pull request** (abajo del formulario).
3. Bajá hasta **Merge pull request** → **Confirm merge**.

Si dice "There isn't anything to compare", ya está mergeado. Si ves otra cosa, mandame captura.
